# ScreenScraper follow-up: access for ordinary users

개발자 계정은 이미 발급받았습니다. 아래 내용은 기존 WebAPI 소개 주제에 후속 답글로 게시하거나 운영진이 안내한 이메일로 보낼 문의문입니다. 신규 개발자 계정 발급 요청이 아닙니다.

## Subject

RetroMeta Studio — enabling scraping with ordinary user accounts

## Message

Hello ScreenScraper team,

Thank you for providing developer access after my introduction of RetroMeta Studio in the WebAPI forum.

I already have developer credentials. I would now like to clarify the procedure for allowing ordinary users to use the publicly distributed application with their own ScreenScraper accounts.

RetroMeta Studio is a free, closed-source Windows desktop application. Version 0.2.0 and public documentation are available here:
https://github.com/moning-1664/retro-meta-studio-releases
https://github.com/moning-1664/retro-meta-studio-releases/releases/tag/v0.2.0

The intended user experience is that each user enters their own ordinary ScreenScraper username and password in the app, without needing to obtain a developer account.

Could you please clarify:

1. Does the developer access already granted cover public distribution and scraping by ordinary users, or is additional application registration, review or approval required?
2. Should the app continue to send its application-specific developer credentials and approved software name together with each user's own account credentials?
3. Is there an activation step or any additional requirement for ordinary user accounts to work with this application?
4. What is the required method for including and protecting developer credentials in a distributed, closed-source desktop client?
5. What attribution, account limits and other conditions should we implement before enabling this feature for the public?

If additional authorization is required, please let me know the exact steps and information you need from me. I can provide a demonstration or an updated evaluation build.

Thank you,
moning-1664

기존 WebAPI 포럼 주제에서 답변을 이어가면 운영진이 이전 승인 내용을 확인하기 쉽습니다. 비밀번호나 개발자 인증 정보를 공개 답글에 포함하지 마세요. 개발자 계정 발급은 완료되었지만, 일반 사용자 배포에 대한 추가 조건과 일반 계정 동작 검증은 운영진 답변 및 구현 검증을 통해 확인해야 합니다.
