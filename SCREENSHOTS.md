# Capture checklist for the public README

Use the real 0.2.0 app with UI language set to English. Capture at a consistent size (for example 1536 x 1000) and save PNG files. Do not use commercial box art, gameplay screenshots, character artwork, publisher logos, or scraped descriptions unless you have verified permission to publish them. Owning a game does not establish permission to publish its artwork.

Use original demo titles (for example `Sample Adventure`, `Sample Puzzle`, `Sample Racer`), your own descriptions, and simple original geometric covers without brand logos. Use your own demo files or licensed homebrew; keep any license and attribution requirements. Do not relabel commercial artwork as demo content. Where possible, leave optional media empty. Crop branded artwork/icons from public captures when their publication rights are unclear; do not change application support labels merely to conceal their meaning.

Capture these views:

1. `01-collection.png`: collection list and one detail panel, with 3–5 demo entries. Shows the main workflow.
2. `02-compare.png`: two demo collections and their differences. Shows reconciliation.
3. No Plan capture is requested: a separate Plan review screen is not available in 0.2.0.
4. `04-settings.png`: General settings with English selected. Do not include account or developer credential fields.
5. Optional `05-scraper.png`: only the scraper overview/status using demo content. Label it "Integration under development"; do not imply successful approved scraping.

Use a neutral demo path such as `C:\DemoLibrary`, hide personal folders/account names, and exclude ROM download sources and authenticated URLs. Send the captures for review before embedding them in the public README. Pending captures are intentionally omitted rather than replaced with fabricated product screenshots.
