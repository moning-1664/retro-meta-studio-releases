# RetroMeta Studio 0.2.0 — First public preview

[README](README.md) | [How to Use](HOW_TO_USE.md) | **Release Notes**

**English** · [한국어](RELEASE_NOTES.ko.md)

Free Windows x64 preview for evaluation and ScreenScraper developer API review.

- Folder-based distribution: extract the entire ZIP and keep the executable with `_internal`.
- English default for new users; existing language preferences are preserved.
- Collection management, metadata/media editing, and side-by-side comparison. A separate Plan review screen is not available.
- No installer or automatic update checker yet.
- ScreenScraper developer authorization is being prepared. Ordinary-account scraping is not yet approved or verified.

Download `RetroMetaStudio-0.2.0-windows-x64.zip`. GitHub's source archives contain public documentation, not the application. Verify the ZIP against `SHA256SUMS.txt` if desired.

This preview is not code-signed. Python is bundled; Microsoft WebView2 Runtime may need to be installed separately. Use a writable folder and back up application and collection data. This release has not been comprehensively tested on a clean Windows installation.
