게임목록 열기

PC 폴더에 있는 게임목록을 앱에 컬렉션(Collection)으로 등록합니다. 한 번 등록하면 탭으로 여러 개를 열어 두고 오가며 편집·비교·복사할 수 있으므로, 이 앱의 모든 작업은 게임목록을 여는 것에서 시작합니다. 등록은 목록 파일을 읽어 오는 과정이며, 이 단계에서 게임목록의 내용이 바뀌지는 않습니다.

이 페이지는 다음 세 가지 상황을 다룹니다.

  • 처음 앱을 실행한 뒤 게임목록을 처음 등록하는 경우
  • 이미 쓰던 게임목록 옆에 다른 게임목록을 추가하는 경우(비교·가져오기·복사를 하려면 최소 두 개가 열려 있어야 합니다)
  • 탭을 닫았다가 같은 게임목록을 다시 여는 경우
참고

이 앱에서 컬렉션은 앱에 등록되어 탭으로 열린 게임목록을 가리킵니다. 여러 게임목록에서 모은 메타데이터를 출처·변경 이력과 함께 보관하는 보관소(Archive) 와는 다른 기능입니다. 저장소는 저장소 페이지에서 설명합니다.

등록하는 순서

  • 시작 화면의 내 게임 목록 열기 또는 탭 옆의 + 를 눌러 컬렉션 추가 창을 엽니다. 이미 다른 컬렉션을 열어 둔 상태에서도 + 로 추가 등록할 수 있습니다.
  • 연결 대상 을 고릅니다. 게임목록이 이 PC의 폴더에 있다면 이 PC (로컬) 을 고릅니다. 외부 드라이브에 있는 게임목록도 PC에서 폴더로 보인다면 같은 방식으로 등록합니다.
  • 게임 목록 폴더 를 지정하고, 실제 목록과 같은 저장 형식 을 고릅니다. 형식이 다르면 목록을 올바르게 읽지 못하므로, 어떤 프론트엔드가 만든 목록인지 먼저 확인합니다.
  • ROM까지 함께 관리하려면 ROM도 Collection에 포함하여 관리 를 켜고 ROM 폴더를 지정합니다. 제목·설명·미디어만 다듬을 계획이라면 켜지 않아도 됩니다.
  • 컬렉션 이름 을 정하고 컬렉션 추가 완료 를 누릅니다.

등록을 마치면 앱이 목록을 읽기 시작합니다. 게임이 많은 경우 한꺼번에 나타나지 않고, 읽기를 마친 시스템부터 차례로 시스템 탐색 영역에 나타납니다. 읽는 도중에 작업을 시작하면 일부 시스템만 대상에 포함될 수 있으므로, 모든 시스템이 보일 때까지 기다린 뒤 작업을 시작하는 것이 안전합니다.

주의

처음 등록하는 게임목록은 편집하기 전에 폴더째 복사해 백업해 두시기 바랍니다. 등록과 읽기만으로는 목록이 바뀌지 않지만, 이후 저장·붙여넣기·정리 작업은 실제 파일에 기록됩니다. 백업이 있으면 잘못된 작업이 있었더라도 원래 상태로 되돌릴 수 있습니다.

입력 항목

번호항목설명
①연결 대상게임목록에 접근하는 방식입니다. 이 PC (로컬) 은 이 PC에서 보이는 폴더(내부·외부 드라이브 포함)를 읽고, Android MTP·Android ADB 는 USB로 연결된 Android 기기의 목록을 읽습니다. 기기 연결은 속도가 느릴 수 있으므로, 대량 편집이 필요하면 목록을 PC로 옮겨 작업하는 편이 편할 수 있습니다. 준비 방법은 기기 연결에서 설명합니다.
②게임 목록 폴더목록 파일과 미디어를 찾는 기준 위치입니다. ES-DE는 gamelists 폴더와 downloaded_media 폴더가 들어 있는 상위 폴더를 지정합니다. ROM이 들어 있는 폴더를 지정하는 것이 아닙니다. 다른 프론트엔드의 폴더 구조는 아래 형식별 폴더 구조를 기준으로 등록합니다. Pegasus는 시스템별 메타데이터 파일들의 상위 폴더, LaunchBox는 Data/Platforms와 Images의 상위 루트를 사용합니다..
③저장 형식ES-DE, EmulationStation, Pegasus, LaunchBox 중에서 실제 게임목록이 사용하는 형식입니다. 저장할 때도 이 형식으로 기록되므로, 선택한 형식과 실제 파일이 일치해야 합니다. 형식을 바꿔 다른 프론트엔드용 목록을 만들고 싶다면 이 항목을 바꾸는 것이 아니라 목록 형식 변환을 사용합니다.
④ROM 관리켜면 게임 파일이 있는 기준 폴더도 지정합니다. 이때부터 ROM 보유 여부를 확인하고, 파일 복사·이동·실행 같은 작업을 쓸 수 있습니다. 끄면 게임 정보와 미디어만 다룹니다.
⑤컬렉션 이름탭과 저장 대상 안내에 표시되는 이름입니다. 비슷한 게임목록을 여러 개 열 때는 Collection-A, Collection-B 처럼 구분하기 쉬운 이름을 붙이면 저장 대상을 착각할 위험이 줄어듭니다.
⑥컬렉션 추가 완료입력한 내용으로 등록하고 목록 읽기를 시작합니다.

목록·미디어·ROM의 위치

게임목록 폴더 안에는 게임 정보(제목·설명과 미디어 경로)가 들어 있고, 미디어(커버·스크린샷 등의 파일)와 ROM(게임 파일)은 서로 다른 폴더나 드라이브에 있어도 됩니다. 앱은 목록에 적힌 경로를 따라 미디어와 ROM을 찾습니다.

  • ROM 관리를 끈 컬렉션에서는 게임 정보와 미디어만 편집할 수 있습니다. ROM이 없어도 정상이므로, 게임이 흐리게 보이더라도 이상이 있는 것이 아닙니다. 번역문을 다듬거나 메타데이터를 채우는 용도라면 ROM 없이도 충분합니다.
  • ROM 위치를 연결하면 ROM 보유 상태 확인, 파일 작업, RetroArch 실행처럼 게임 파일이 필요한 기능을 함께 쓸 수 있습니다.
  • 외부 드라이브에 있는 파일은 드라이브가 연결되어 있어야 읽을 수 있습니다. 드라이브 문자가 바뀌면 경로가 어긋날 수 있으므로, 같은 드라이브를 늘 같은 문자로 연결해 쓰는 것이 좋습니다.

여러 컬렉션 다루기

  • 탭을 눌러 작업 대상을 바꿉니다. 편집·가져오기·붙여넣기는 현재 탭을 기본 대상으로 하므로, 실행 전에 탭 이름과 상단 요약 영역의 이름을 함께 확인하면 어느 게임목록에 저장되는지 알 수 있습니다.
  • 탭을 드래그해 순서를 바꿀 수 있습니다. 자주 비교하는 두 컬렉션을 나란히 두면 오가기 편합니다.
  • 탭을 닫은 게임목록은 등록 정보가 남아 있으므로, 이전에 등록된 컬렉션 에서 다시 열 수 있습니다. 다시 열 때 폴더를 처음부터 지정하지 않아도 됩니다.
  • 등록 목록에서 제거 와 실제 파일 삭제 는 다른 동작입니다. 제거는 앱의 등록 목록에서만 빼며, 폴더와 파일은 그대로 남습니다. 삭제는 실제 파일을 지우므로 확인 창의 대상 이름과 개수를 반드시 읽고 진행합니다.
  • 앱 밖에서 파일을 바꿨다면(예: 탐색기에서 ROM을 옮기거나 다른 프로그램으로 목록을 고친 경우) 다시 스캔 으로 현재 상태를 읽어 옵니다. 읽어 오지 않으면 화면에는 이전 상태가 남아 있어 실제 파일과 어긋날 수 있습니다.

문제 해결

폴더를 감지하지 못합니다.

선택한 위치에 목록 파일이 있는지 확인합니다. ES-DE는 ROM 폴더가 아니라 gamelists·downloaded_media 가 들어 있는 상위 폴더를 지정해야 합니다. 저장 형식을 잘못 고른 경우에도 감지되지 않을 수 있으므로 형식도 함께 확인합니다.

목록은 보이는데 게임이 흐리게 나옵니다.

ROM 관리를 끈 컬렉션이거나 ROM 경로가 연결되지 않은 상태입니다. 게임 정보만 편집하는 용도라면 정상입니다. 게임 파일까지 다루려면 ROM 위치를 연결합니다.

시스템이 일부만 보입니다.

읽기가 아직 끝나지 않았을 수 있습니다. 잠시 기다린 뒤에도 같다면 탐색·검색·정렬의 검색 범위 점검 순서를 따라 필터와 빈 시스템 숨기기를 확인하고, 그래도 같다면 다시 스캔 을 실행합니다.

Android 기기의 게임목록이 열리지 않습니다.

USB 연결 방식과 기기 상태를 확인합니다. 자세한 점검 순서는 기기 연결을 참고하시기 바랍니다.
