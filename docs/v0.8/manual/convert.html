목록 형식 변환

한 게임목록의 내용을 다른 프론트엔드 형식(ES-DE, EmulationStation, Pegasus, LaunchBox)의 새 게임목록으로 변환하는 고급 기능입니다. 원본은 바뀌지 않으며, 지정한 새 폴더에 변환 결과가 만들어집니다. 만들어진 새 게임목록은 컬렉션(Collection)으로 열어 확인하고 편집할 수 있습니다.

처음 사용하는 분은 이 기능이 필요하지 않을 수 있습니다. 같은 프론트엔드의 게임목록 사이에서 정보를 옮기는 일은 복사·붙여넣기, 목록 간 비교, 컬렉션에서 가져오기로 해결됩니다.

용도

  • ES-DE로 정리한 게임목록을 Pegasus나 LaunchBox에서도 쓰고 싶을 때: 프론트엔드를 바꾸거나 함께 쓰면서 정리해 둔 정보를 다시 입력하지 않아도 됩니다.
  • 형식을 옮기면서 정보와 미디어를 그대로 가져가고 싶을 때
  • 원본은 그대로 두고 다른 형식의 사본을 먼저 만들어 확인하고 싶을 때

메뉴와 적용 대상

  • 변환할 컬렉션 탭에서 우클릭해 목록 정보를 엽니다.
  • 다른 형식으로 변환…을 선택합니다.
  • 만들 형식과 새 게임목록을 저장할 폴더를 고릅니다.
  • 미리보기에서 만들어질 게임목록과 처리할 정보·파일을 확인하고 적용합니다.
  • 끝나면 새 컬렉션을 열어 제목·설명·미디어 연결을 확인합니다.

선택 항목

항목내용
형식ES-DE, EmulationStation, Pegasus, LaunchBox 중에서 만들 프론트엔드 형식을 고릅니다.
저장 폴더새 게임목록을 만들 폴더입니다. 원본 폴더와 다른 곳을 지정하는 것이 안전합니다. 원본과 같은 형식·같은 루트는 거부됩니다. 이미 같은 형식으로 등록한 대상 루트도 중복 등록할 수 없습니다. 원본 보존을 위해 별도 폴더를 사용합니다.
미리보기만들어질 게임목록과 처리할 정보·파일을 적용 전에 보여 줍니다. 빠지거나 바뀌는 항목이 있는지 이 단계에서 확인합니다.

유의 사항

  • 형식마다 저장할 수 있는 정보와 미디어 종류가 다릅니다. 미리보기에서 빠지는 항목이 없는지 먼저 확인합니다. 변환하는 형식이 지원하지 않는 항목은 새 게임목록에 담기지 않을 수 있습니다.
  • 변환은 새 폴더에 새 게임목록을 만드는 작업입니다. 기존 게임목록을 비교하거나 덮어쓰는 기능이 아니므로, 이미 쓰고 있는 게임목록에 정보만 보태려면 컬렉션에서 가져오기를 사용합니다.
  • 원본과 새 게임목록의 이름·경로를 구분해 두면 나중에 목록 간 비교로 결과를 대조하기 쉽습니다.
  • 변환 결과가 실제 프론트엔드에서 보이려면 해당 프론트엔드가 그 폴더를 읽도록 설정되어 있어야 합니다. 변환 결과를 읽는 경로는 사용하는 프론트엔드에서 지정합니다. 이 앱은 새 형식의 파일과 미디어를 만들며 각 프론트엔드의 외부 설정을 자동으로 바꾸지 않습니다.

끝난 뒤

  • 새 컬렉션을 열어 제목·설명·평점이 원본과 같은지 대표 게임 몇 개로 확인합니다.
  • 커버·스크린샷·동영상이 모두 연결되어 있는지 미디어 탭에서 확인합니다.
  • 원본과 한꺼번에 점검하고 싶다면 두 컬렉션을 탭으로 열고 목록 간 비교를 사용합니다. 다만 형식이 다르면 시스템 폴더 이름이 달라질 수 있어, 시스템을 하나씩 지정해 비교하는 편이 연결에 유리합니다.

문제 해결

변환한 게임목록에서 일부 미디어가 안 보입니다.

대상 형식이 그 미디어 종류를 지원하지 않거나 폴더 규칙이 다를 수 있습니다. 미리보기의 처리 목록과 새 컬렉션의 미디어 탭을 대조합니다.

변환 후 프론트엔드에서 새 게임목록이 보이지 않습니다.

이 앱은 새 게임목록 파일과 폴더를 만들 뿐이며, 프론트엔드가 해당 폴더를 읽도록 하는 설정은 프론트엔드 쪽에서 해야 합니다. 각 프론트엔드의 폴더 설정을 확인합니다.

원본이 바뀌었을까 걱정됩니다.

변환은 원본을 수정하지 않는 작업입니다. 그래도 걱정된다면 변환 전에 원본 폴더를 복사해 둡니다.
