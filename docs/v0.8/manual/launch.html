RetroArch 실행

메타데이터를 고친 게임이 실제로 제대로 실행되는지 확인하려면, 에뮬레이터를 따로 열고 폴더를 찾아 ROM을 고르는 과정을 매번 거쳐야 합니다. 게임이 수십, 수백 개이면 이 반복만으로도 정리 작업의 흐름이 끊깁니다. 이 기능은 정리한 게임을 편집하던 화면에서 바로 RetroArch로 실행합니다. 시스템마다 기본 코어를 정해 두고, 특정 게임만 다른 코어로 실행하도록 게임별로 따로 설정할 수도 있습니다.

RetroArch를 쓰지 않거나 PC에서 게임을 실행해 볼 필요가 없다면 이 페이지는 건너뛰어도 됩니다. 게임목록 편집, 비교, 복사 등 다른 기능에는 영향이 없는 선택 기능입니다. 이 기능은 RetroArch를 대신 설치하거나 설정해 주는 기능이 아니라, 이미 PC에 갖추어진 RetroArch를 편집 화면에서 호출하는 연결 고리에 해당합니다.

용도

  • 편집 결과를 바로 확인할 때: 제목이나 ROM 연결을 고친 뒤, 그 게임이 PC에서 정상적으로 시작되는지 편집 화면을 벗어나지 않고 확인합니다. ROM 파일 경로나 이름을 정리한 직후의 점검에 특히 유용합니다.
  • 시스템별 코어를 한 번에 정할 때: 시스템마다 사용할 코어를 미리 지정해 두면, 같은 시스템의 게임은 매번 코어를 고르지 않아도 같은 방식으로 실행됩니다.
  • 특정 게임만 예외로 둘 때: 대부분의 게임은 시스템 기본 코어로 실행하되, 호환성 문제가 있는 일부 게임만 다른 코어로 실행하도록 따로 지정합니다.

준비

실행에 필요한 요소는 모두 PC에 갖추어져 있어야 합니다. 이 앱은 RetroArch나 코어, BIOS, ROM을 제공하거나 대신 설치하지 않습니다. 준비물 중 하나라도 빠져 있으면 실행이 시작되지 않거나, 시작되더라도 곧바로 오류로 끝날 수 있습니다.

준비물설명
RetroArchPC에 설치되어 있어야 합니다. 앱에서는 설치된 실행 파일의 위치만 지정합니다.
코어시스템에 맞는 코어가 RetroArch에 설치되어 있어야 합니다. 코어는 에뮬레이터 본체 역할을 하는 플러그인이며, 같은 시스템에도 여러 코어가 있어 호환성과 성능, 지원하는 파일 형식이 서로 다를 수 있습니다.
BIOS시스템에 따라 필요합니다. 필요 여부와 파일 이름은 코어마다 다르므로, 코어가 요구하는 위치(RetroArch의 system 폴더 등)에 둡니다.
ROM게임목록에 ROM이 연결되어 있고, 앱에서 해당 파일에 접근할 수 있어야 합니다. 외부 드라이브에 있는 ROM은 드라이브가 연결되어 있어야 합니다.

설정하고 실행하기

  • 왼쪽 아래 톱니바퀴로 설정 을 열고 에뮬레이터 를 엽니다. 전체 옵션 구성은 설정에서도 확인할 수 있습니다.
  • RetroArch 실행 파일 위치를 지정합니다. 설치형이든 압축을 풀어 쓰는 형태이든, 실제로 실행되는 파일을 가리켜야 합니다.
  • 시스템별 코어 를 연결합니다. 이 값이 해당 시스템의 기본 코어가 됩니다. 시스템을 하나씩 설정하는 방식이므로, 자주 쓰는 시스템부터 지정해 두면 됩니다.
  • ROM이 있는 게임목록에서 게임을 선택합니다. 제목이 흐리게 표시되면 ROM이 없는 상태이므로 실행할 수 없습니다.
  • 상세 영역 또는 아케이드 보기의 게임 실행 을 누릅니다.

실행하면 RetroArch가 별도의 창으로 열리고, 선택한 게임이 지정된 코어로 시작됩니다. 앱은 열린 상태로 남으므로, 게임을 확인한 뒤 RetroArch를 종료하고 편집 화면으로 돌아와 작업을 이어 갈 수 있습니다. 실행은 ROM을 읽어 게임을 시작하는 동작이며, 게임목록의 메타데이터를 바꾸지 않습니다.

참고

RetroArch는 처음 실행할 때 자체 설정 파일과 폴더를 만듭니다. 코어와 BIOS의 위치는 RetroArch 쪽 설정을 따르므로, 앱의 설정만 마쳤다고 해서 코어가 자동으로 내려받아지지는 않습니다.

게임별 설정

시스템 기본 코어는 같은 시스템의 모든 게임에 적용됩니다. 그중 특정 게임만 다른 코어나 설정으로 실행하려면 상세 영역의 ROM 탭에서 실행 관련 항목을 조정합니다. 게임별 설정은 그 시스템의 기본 설정보다 우선합니다.

설정 위치적용 범위알맞은 경우
설정 > 에뮬레이터시스템 전체대부분의 게임이 같은 코어로 잘 실행될 때
상세 영역의 ROM 탭선택한 게임 하나특정 게임만 다른 코어가 필요할 때

예를 들어 한 시스템의 게임 대부분은 가볍고 빠른 코어로 충분하지만, 일부 게임에서만 화면이나 소리 문제가 생긴다면 그 게임에만 정확도가 높은 코어를 지정하는 식으로 활용합니다. 시스템 전체를 바꾸지 않고 문제가 되는 게임만 따로 다룰 수 있다는 점이 장점입니다.

실행 코어는 게임별 지정값, 시스템 기본값, 사용 가능한 기본 코어 후보 순으로 결정합니다. ROM 탭에서 시스템 기본값으로 저장할지 이 게임에만 지정할지 선택합니다.

참고

게임별 설정을 지정한 뒤 시스템 기본 코어를 바꾸더라도, 게임별로 지정한 게임은 바뀌지 않습니다. 시스템 전체를 새 코어로 통일하려면 게임별 설정이 남아 있는지 함께 확인합니다.

연결 기기의 ROM

현재 앱은 기기 Collection의 ROM을 PC RetroArch로 직접 실행하지 않습니다. ROM 관리를 사용하고 실제 ROM에 접근할 수 있는 로컬 Collection에서 실행합니다. RetroArch와 코어·필요한 BIOS는 사용자가 준비합니다.

문제 해결

게임 실행 버튼을 쓸 수 없습니다.

버튼은 실행에 필요한 조건이 갖추어지지 않으면 사용할 수 없습니다. ROM 보유·접근 상태, RetroArch 경로, 시스템 코어 설정을 차례로 확인합니다. ROM이 외부 드라이브에 있다면 드라이브가 연결되어 있는지도 확인합니다.

RetroArch가 열렸는데 게임이 시작되지 않습니다.

코어가 이 ROM 형식을 지원하는지, 필요한 BIOS가 올바른 위치에 있는지, ROM 파일 경로가 맞는지 확인합니다. 같은 시스템에 다른 코어를 연결하면 해결되는 경우도 있습니다. 문제가 특정 게임에서만 생긴다면 해당 게임에만 다른 코어를 지정해 봅니다.

일부 게임만 실행되지 않습니다.

압축 파일이나 여러 디스크로 구성된 게임은 코어에 따라 지원 여부가 다릅니다. 코어의 지원 확장자와 해당 게임의 ROM 형식을 비교합니다.

코어를 바꿨는데 이전 코어로 실행됩니다.

해당 게임에 게임별 설정이 지정되어 있을 가능성이 큽니다. 상세 영역의 ROM 탭에서 게임별 설정을 확인하고, 시스템 기본 코어를 따르게 하려면 그 지정을 정리합니다. ROM 탭의 게임별 코어 선택에서 지정 없음(시스템 기본값 사용)을 선택해 개별 지정을 해제합니다.

ROM의 용량이나 보관 위치를 정리하고 싶습니다.

ROM과 미디어의 저장 위치와 용량 관리는 파일 관리에서 다룹니다. SD카드 등 용량 제약이 있는 장치로 옮길 때의 저장공간 관리도 같은 페이지를 참고합니다.
