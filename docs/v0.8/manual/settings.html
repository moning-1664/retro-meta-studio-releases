설정

앱의 표시 방식, 에뮬레이터 연결, 스크랩 서비스, 초기화 등 동작 전반을 바꾸는 곳입니다. 왼쪽 아래 톱니바퀴로 엽니다. 왼쪽의 분류를 고르면 해당 옵션이 오른쪽에 나타납니다. 이 페이지는 분류별 옵션이 무엇을 바꾸는지, 바꾸면 어떤 영향이 있는지를 찾아보는 참조용입니다.

일반 설정은 바꾸는 즉시 반영·저장됩니다. 별도의 저장 버튼이 없고, 창을 닫아도 이전 값으로 돌아가지 않습니다. 값을 되돌리려면 해당 옵션을 다시 고릅니다. 시험 삼아 값을 바꿔 보았다면, 바꾸기 전의 값을 기억해 두었다가 직접 되돌려야 합니다.

분류별 안내

분류마다 다루는 범위가 다르며, 기능별 설정은 해당 기능의 페이지에서 자세히 설명합니다. 어떤 옵션이 어느 분류에 있는지 찾기 어렵다면 아래 표에서 하고 싶은 일에 가까운 분류를 먼저 고릅니다.

화면

화면 분류는 게임 정보 자체가 아니라 앱이 보이는 방식만 바꿉니다. 어떤 값을 고르더라도 게임목록이나 미디어 파일은 변경되지 않으므로, 부담 없이 조정해 보아도 됩니다.

옵션설명
테마밝고 어두운 표시와 강조색을 바꿉니다. 게임 정보는 바뀌지 않습니다. 밤에 오래 작업하거나 모니터 환경에 맞춰 눈의 피로를 줄이고 싶을 때 조정합니다.
UI 배율80~130% 범위에서 5% 단위로 글자와 조작 영역 크기를 바꿉니다. 해상도가 높은 모니터에서 글자가 작게 보이면 높이고, 한 화면에 더 많은 항목을 보고 싶으면 낮춥니다.
화면 밀도목록과 편집 영역의 간격을 조절합니다. 간격을 좁히면 한 화면에 더 많은 줄이 보입니다. 현재 활성화된 설정만 적용할 수 있습니다. 화면에서는 테마·강조색·UI 배율·표시 밀도를, 게임리스트에서는 기본 보기·복사 범위·우선 정렬 등을 조정합니다.

화면이 좁아 항목이 잘리면 배율을 낮추거나 시스템 영역·상세 영역 너비를 함께 조절합니다. 배율만 낮추어도 해결되지 않는다면 창 크기를 키워 봅니다.

에뮬레이터

RetroArch 실행 파일의 위치와 시스템별 기본 코어를 지정하는 분류입니다. 여기서 정한 값은 편집 화면의 게임 실행 이 사용하며, 특정 게임만 다른 코어로 실행하려면 게임별 설정을 따로 지정합니다. 지정 방법과 준비물, 문제 해결은 RetroArch 실행에서 설명합니다.

고급

진단·관리·초기화 기능이 있습니다. 문제 상황에서 앱의 상태를 점검하거나 설정을 처음 상태로 돌릴 때 사용하는 분류이며, 일상적인 편집에는 필요하지 않습니다.

초기화와 삭제는 대상과 범위가 각각 다릅니다. 예를 들어 설정을 되돌리는 것과 작업 기록을 지우는 것, 파일을 지우는 것은 서로 다른 작업입니다. 실행하기 전에 확인 창에 표시된 설정·기록·파일의 범위를 읽고 진행합니다. 화면 설정 초기화는 테마·밀도·크기 등 appearance 설정을 기본값으로 되돌립니다. 게임 목록·미디어·ROM을 삭제하는 동작이 아닙니다.

주의

초기화나 삭제를 실행하기 전에는 게임목록·미디어 폴더와 보관소(Archive) 폴더를 따로 복사해 두시기 바랍니다.

앱 정보

버전 확인, 업데이트 확인, 설명서 열기, 외부 구성요소 라이선스를 볼 수 있습니다. 문의나 문제 보고를 올릴 때는 이 화면에서 현재 버전을 확인해 함께 적습니다. 설명서 버튼은 앱에 포함된 로컬 문서를 먼저 열고, 없으면 웹 문서로 연결합니다. 인터넷에 연결되지 않은 환경에서도 포함된 문서는 볼 수 있습니다.

설치와 업데이트

배포 형식은 두 가지이며, 설정과 작업 기록의 보관 방식은 형식에 따라 다를 수 있습니다. 설정·등록 목록과 캐시는 앱의 데이터 경로를 사용합니다. 실행 파일을 교체하기 전에 기존 데이터 폴더와 별도 지정한 Archive를 보관하고, 버전 이동 후 등록 경로를 확인합니다.

방식설명알맞은 경우
Setup설치 프로그램으로 설치합니다.한 PC에서 계속 사용할 때
Portable압축을 풀어 바로 실행합니다.설치 없이 시험해 보거나 폴더째 옮겨 쓸 때

공개 릴리즈의 Assets에서 배포 파일을 받습니다. 두 형식 모두 처음 실행할 때에는 게임목록을 미리 백업해 두기를 권장합니다.

업데이트 순서

  • 앱 정보에서 현재 버전을 확인합니다.
  • 앱을 종료합니다.
  • 게임목록·미디어·보관소(Archive) 폴더를 따로 복사해 백업합니다.
  • 사용하는 배포 형식에 맞는 새 버전을 설치하거나 압축을 풉니다.
  • 앱을 열어 기존 게임목록과 설정, 저장한 정보가 그대로인지 확인합니다.

업데이트 후 값이 달라져 있다면 백업해 둔 폴더와 비교해 원인을 확인하고, 해결되지 않으면 버전·재현 순서와 함께 문의합니다.

문제 해결

설정을 닫았는데 값이 바뀌어 있습니다.

일반 설정은 바꾸는 즉시 반영되며 닫을 때 취소되지 않습니다. 이전 상태가 필요하면 해당 값을 다시 고릅니다.

초기화하면 게임 파일도 지워집니까?

초기화와 삭제는 범위가 다릅니다. 확인 창에 나오는 범위를 읽고 진행합니다. 게임 파일의 삭제는 파일 관리에서만 이루어집니다. 화면 설정 초기화와 게임 파일 삭제는 별도입니다. 화면 초기화는 appearance 설정에 적용됩니다.

글자가 너무 작거나 화면이 잘립니다.

화면 분류에서 UI 배율과 화면 밀도를 조정합니다. 항목이 잘리는 경우에는 배율을 낮추거나 영역 너비를 함께 조절합니다.

게임 실행이 되지 않습니다.

에뮬레이터 분류에서 RetroArch 실행 파일 경로와 해당 시스템의 코어가 지정되어 있는지 확인합니다. 그 밖의 원인은 RetroArch 실행의 문제 해결을 참고합니다.
