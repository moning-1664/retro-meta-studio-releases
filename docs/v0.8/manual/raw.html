메타데이터 직접 편집

선택한 게임의 목록 원문(XML 등)을 직접 고칩니다. 일반 입력란에 나타나지 않는 태그나 값을 다뤄야 할 때, 또는 입력란으로 표시된 값이 실제 파일에 어떻게 기록되어 있는지 확인하고 싶을 때에 사용하는 고급 기능입니다. 제목·설명만 바꾸는 경우라면 메타데이터·미디어 편집의 일반 입력란이 더 안전합니다.

원문을 고치는 만큼 잘못 입력하면 게임목록이 올바르게 읽히지 않을 수 있습니다. 작업 전에 게임목록을 백업해 두시기 바랍니다.

여는 곳

게임 상세 영역의 ROM 탭에서 Raw Text (Metadata) 를 펼칩니다. 원문을 고친 뒤 상세 영역의 저장 을 누릅니다.

쓰임새

  • 일반 입력란에 없는 태그를 추가하거나 고칠 때
  • 입력란에 보이는 값과 실제 원문이 다른 것처럼 보일 때 원문을 대조할 때
  • 프론트엔드가 인식하는 값을 직접 확인할 때

원문의 형식은 게임목록의 저장 형식(ES-DE, EmulationStation, Pegasus, LaunchBox)에 따라 다릅니다. 형식별로 어떤 태그가 쓰이는지는 각 프론트엔드의 설명서를 참고합니다.

저장할 때 일어나는 일

  • 앱이 원문을 검증합니다. XML은 태그 닫힘 같은 구문 오류를 검사합니다.
  • 오류가 있으면 저장이 멈추고 원문 아래에 오류 내용과 위치가 나옵니다. 이때 게임목록 파일은 바뀌지 않습니다. 원문 검증이나 동시 수정 검사에 실패하면 성공으로 저장하지 않고 오류와 초안을 유지합니다. 입력 내용과 원본을 대조한 뒤 다시 저장합니다.
  • 검증을 통과하면 해당 컬렉션(또는 보관소(Archive))에 기록합니다.

검증은 구문이 올바른지만 확인합니다. 태그 이름이 프론트엔드에서 실제로 쓰이는지, 값의 의미가 맞는지는 확인하지 않을 수 있으므로 XML 구문 외에도 게임 대상과 경로·동시 변경 등 저장 가능한 상태를 검사합니다. 모든 태그 값의 게임학적 의미나 사실까지 판단하는 도구는 아닙니다., 저장한 뒤에는 프론트엔드에서 게임이 정상적으로 보이는지 확인하는 것이 안전합니다.

참고 사항

  • 일반 입력란과 원문을 동시에 고치면 저장할 수 없습니다. 한쪽을 먼저 저장하거나 되돌려 정리한 뒤 다른 쪽을 저장합니다.
  • 원문을 읽은 뒤 파일이 외부에서 바뀌었다면 저장 오류가 날 수 있습니다. 최신 내용을 다시 읽어 변경 사항을 합칩니다.
  • 편집 대상은 선택한 게임의 목록 원문입니다. ROM 파일의 바이너리를 편집하는 기능이 아닙니다.
  • 원문에 적힌 경로와 실제 파일 위치가 어긋나지 않도록 함께 관리합니다. 경로를 고쳤다면 해당 파일이 그 위치에 있는지 확인합니다.
  • 여러 게임에 같은 변경을 적용하는 용도가 아닙니다. 이 기능은 선택한 한 게임을 다룹니다.

문제 해결

문법 오류가 나옵니다.

오류 메시지에 나온 태그 이름과 닫힘 기호를 확인합니다. 원본과 비교해 고친 부분만 좁혀 보면 빠르게 찾을 수 있습니다. 특수 문자(&, <, >)를 글자 그대로 쓰면 구문 오류가 되는 경우가 많으므로 XML 규칙에 맞게 표기해야 합니다.

일반 필드와 원문을 함께 저장할 수 없다고 나옵니다.

저장하지 않은 일반 필드 변경과 원문 변경을 나누어 처리합니다. 안내를 닫기 전에 입력한 내용은 따로 복사해 둡니다.

저장 오류가 나고 원문이 이전 내용과 다릅니다.

원문을 읽은 뒤 파일이 외부에서 바뀌었을 수 있습니다. 최신 내용을 다시 읽은 뒤 필요한 변경만 다시 적용합니다.
