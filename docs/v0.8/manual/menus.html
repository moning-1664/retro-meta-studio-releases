메뉴와 단축키

같은 이름의 기능이라도 어디에서 여느냐에 따라 적용 대상이 달라집니다. 시스템 우클릭 메뉴는 그 시스템 전체에, 게임 우클릭 메뉴는 선택한 게임에 적용됩니다. 이 페이지는 메뉴가 열리는 위치별로 항목과 적용 대상을 정리하여, 의도하지 않은 범위로 작업이 실행되는 일을 줄이는 데 목적이 있습니다.

시스템 우클릭 메뉴

시스템 단위로 한꺼번에 처리할 때 씁니다. 게임 수가 많은 시스템에서는 실행 전에 미리보기나 확인 창이 나오면 대상 개수를 읽고 진행합니다.

항목하는 일안내
컬렉션에서 가져오기열어 둔 다른 게임목록에서 이 시스템에 맞는 후보를 찾아 메타데이터를 가져오는 작업을 시작합니다.가져오기
스크랩이 시스템의 게임을 온라인 서비스에서 검색합니다. 현재 메타데이터와 비교한 뒤 적용할 항목을 고를 수 있습니다.온라인 스크랩
번역 파일로 내보내기/가져오기 (.csv)설명을 .csv 파일로 내보내 외부에서 번역·편집한 뒤 다시 가져옵니다.CSV 번역
정리ROM이 없는 항목과 미디어를 정리합니다. 파일에 영향을 줄 수 있으므로 대상 목록을 먼저 확인합니다.파일 관리
폴더 이름 변경ROM·목록·미디어 폴더 이름을 함께 바꿉니다. 시스템 탐색의 이름 표시만 바꾸는 것이 아니라 실제 폴더 이름이 바뀝니다.외부 드라이브
저장소 이동시스템을 다른 위치로 옮깁니다. 시스템의 저장소 이동은 내부·외부 드라이브 사이에서 해당 시스템 파일을 옮기는 기능입니다. Archive에 보관하는 기능과 구분합니다.외부 드라이브
제목 태그·디스크 표기 정리제목의 언어 태그와 디스크 순서 표기를 정리합니다. 적용 전에 변경 내용을 미리 볼 수 있습니다.메타데이터·미디어 편집

게임 우클릭 메뉴

선택한 게임에만 적용됩니다. 여러 게임을 선택한 상태라면 선택한 전체가 대상이 됩니다.

항목하는 일안내
복사 · 붙여넣기선택한 게임의 정보를 다른 게임목록으로 보냅니다. 탐색기의 복사·붙여넣기와 비슷한 방식으로 동작합니다.복사·붙여넣기
스크랩선택한 게임의 후보를 온라인에서 찾습니다.온라인 스크랩
파일 작업ROM 등 실제 파일의 복사·이동·삭제를 시작합니다. 삭제는 되돌리기 어려우므로 대상 이름과 개수를 확인합니다.파일 관리
Archive로 보내기선택한 게임의 정보를 보관소(Archive)에 보관합니다.저장소

상단 요약 도구

현재 열려 있는 컬렉션 전체를 대상으로 하는 도구입니다.

항목하는 일안내
비교하기상대 컬렉션과 범위를 골라 두 게임목록의 차이를 보는 비교를 시작합니다.게임목록 비교
가져오기다른 컬렉션 또는 저장소에서 메타데이터를 가져옵니다.가져오기
다시 스캔게임목록과 실제 파일의 상태를 다시 읽습니다. 앱 밖에서 파일을 바꾼 뒤에 씁니다.탐색·검색·정렬

대상 확인하는 법

  • 여러 게임을 선택했다면 작업 이름 옆에 개수가 표시됩니다. 실행하기 전에 대상 이름과 개수를 확인하면 의도하지 않은 전체 작업을 피할 수 있습니다.
  • 하단 상태 영역의 선택 수도 함께 보면 확실합니다.
  • 회색(비활성) 항목은 지금 할 수 없는 작업입니다. 마우스를 올리면 이유가 나오는 항목도 있습니다.

비활성이 되는 경우

  • 선택한 게임에 필요한 자료(ROM·파일)가 없을 때
  • 필요한 파일에 접근할 수 없을 때(기기 분리, 외부 드라이브 연결 끊김)
  • 현재 연결 방식이 그 작업을 지원하지 않을 때
  • 컬렉션인지 저장소인지에 따라 쓸 수 없는 작업일 때

비활성 항목이 필요한 작업이라면, 먼저 위 조건 중 어느 것에 해당하는지 확인하고 ROM 연결이나 드라이브 연결을 복구한 뒤 다시 시도합니다.

단축키

키하는 일
Ctrl+S상세 영역의 메타데이터 저장
Ctrl+C선택한 게임 복사
Ctrl+V붙여넣기
F1설명서 열기
Esc현재 창 닫기

입력 중인 창이나 확인 창이 열려 있으면 그 창의 동작이 먼저입니다. 예를 들어 텍스트 입력란에 커서가 있을 때의 Ctrl+C·Ctrl+V 는 게임 복사가 아니라 입력란의 글자 복사로 동작하는 것이 일반적입니다. 입력란·텍스트 영역·선택 상자에 초점이 있으면 목록 단축키는 동작하지 않습니다. Ctrl+C·Ctrl+V는 입력 내용의 복사·붙여넣기로 사용합니다.

문제 해결

원하는 메뉴 항목이 보이지 않습니다.

메뉴를 연 위치를 확인합니다. 시스템 우클릭에는 있지만 게임 우클릭에는 없는 항목이 있습니다. 또 컬렉션 탭인지 Archive 탭인지에 따라 항목이 달라질 수 있습니다.

항목이 회색으로 나옵니다.

위의 비활성 조건을 순서대로 확인합니다. ROM 관리를 끈 컬렉션에서는 ROM이 필요한 작업이 비활성일 수 있습니다.

단축키가 반응하지 않습니다.

입력 창이나 확인 창이 열려 있지 않은지 확인합니다. 열려 있다면 그 창을 먼저 닫거나 마무리합니다.
