메타데이터·미디어 편집

게임의 제목·설명·평점 같은 메타데이터를 고치고, 연결된 커버·스크린샷·동영상·매뉴얼이 제대로 걸려 있는지 확인합니다. 게임목록에 보이는 표시 제목과 실제 ROM 파일명은 서로 다른 값으로 관리되므로, 제목을 고쳐도 ROM 파일 이름은 바뀌지 않습니다. 이 페이지는 일상적인 편집 작업의 기본이 되는 내용이며, 대량 편집이 필요하면 CSV 번역이나 온라인 스크랩이 더 빠릅니다.

용도

  • 제목·설명을 고치거나 번역문을 다듬을 때
  • 평점·출시일·장르처럼 비어 있는 항목을 채울 때
  • 커버·스크린샷·동영상·매뉴얼이 연결되어 있는지 점검할 때
  • ROM 파일의 식별값(SHA256)을 확인하거나 게임별 실행 설정을 확인할 때

편집 순서

  • 게임을 선택하고 상세 영역의 메타데이터 탭을 엽니다. 아케이드 보기에서는 고칠 내용 자체를 더블클릭합니다.
  • 내용을 고칩니다.
  • 상세 영역 아래의 저장 대상 을 확인하고 저장 또는 Ctrl+S 를 누릅니다. 저장 대상은 현재 탭의 컬렉션 또는 보관소(Archive)이며, 여러 게임목록을 열어 둔 상태에서는 의도한 대상인지 반드시 확인합니다.

상세 영역의 세 탭

탭보이는 것할 수 있는 일
메타데이터제목·설명·평점·출시일·개발사·배급사·장르·지역·인원값을 입력해 저장합니다. 목록 파일에 기록되는 정보는 이 탭의 항목입니다.
미디어연결된 커버·스크린샷·동영상·매뉴얼미리보기, 확대, 파일 위치 확인, 해당 파일에 대한 작업 메뉴를 사용합니다.
ROM파일명·시스템·크기·보유 상태·SHA256, 실행 설정SHA256 계산하기, 게임별 실행 설정, 원문 메타데이터 보기를 사용합니다.
참고

프론트엔드에 따라 저장할 수 있는 항목이 다를 수 있습니다. 지원 항목은 아래 형식별 저장 항목 표를 참고하세요. 목록 형식 변환의 미리보기는 지원하지 않는 필드·미디어와 프론트엔드 전용 값의 제외 개수를 표시합니다.

저장되는 시점

저장 방식

리스트·카드는 저장 버튼, 아케이드는 편집을 마치면 자동 저장입니다. 편집을 시작하기 전에 게임목록 폴더를 복사해 원본을 보관하세요. 앱의 작업 백업은 전체 폴더 백업과 범위가 다릅니다.

보기 모드에 따라 저장되는 시점이 다릅니다.

보기 모드저장 방법
리스트·카드저장 또는 Ctrl+S 를 눌러야 합니다. 저장하지 않고 다른 게임을 선택하면 입력한 내용이 사라집니다. 게임·탭을 옮기기 전에 저장하세요.
아케이드내용을 더블클릭해 입력한 뒤 다른 읽기 영역을 누르면 자동으로 저장됩니다.

저장 오류가 나면 입력한 내용은 그대로 남습니다. 연결과 쓰기 권한을 해결한 뒤 다시 저장합니다. Android 기기나 외부 드라이브의 게임목록이라면 연결이 끊기지 않았는지부터 확인합니다.

메타데이터가 없는 게임

ROM은 있지만 게임목록에 게임 정보 항목이 없는 경우가 있습니다. 이런 항목에서 제목을 고치려 하면 아래 선택 창이 열립니다. 제목이 어디에 기록될지를 정하는 단계입니다.

선택결과
메타데이터 생성게임 정보 항목을 새로 만들고 표시 제목을 기록합니다. 게임목록에 보이는 이름이 바뀌며, ROM 파일은 그대로입니다.
파일명 수정실제 ROM 파일명을 바꾸는 입력 창이 열립니다. 확장자는 그대로 둡니다.
취소창을 닫고 아무것도 바꾸지 않습니다.
주의

게임목록에 보이는 제목만 만들고 싶다면 메타데이터 생성 을 고릅니다. 파일명 수정은 ROM 파일 이름 자체를 바꿉니다. 프론트엔드나 RetroArch가 파일명을 기준으로 게임을 찾는 경우 파일명을 바꾸면 연결이 어긋날 수 있으므로, 필요한 경우가 아니라면 표시 제목만 바꾸시기 바랍니다.

미디어와 원본 파일

미디어는 목록에 경로로 연결된 별도 파일입니다. 상세 영역에 그림이 보이는 것과 원본 파일에 접근할 수 있는 것은 별개의 문제이므로 둘 다 확인합니다.

  • 커버·스크린샷은 미리보기와 확대로 확인하고, 파일 위치 확인으로 실제 파일이 어디에 있는지 열어 볼 수 있습니다.
  • 동영상·매뉴얼은 연결된 파일이 있어야 열립니다.
  • 보관소(Archive)의 외부 연결 자료는 원래 보관된 위치가 연결되어 있어야 열립니다.
  • 커버가 비어 있는 게임을 한꺼번에 찾으려면 보기 모드의 카드 보기가 편리합니다.

파일 식별과 제목 태그

  • SHA256 계산하기 (ROM 탭): 실제 파일을 읽어 식별값을 계산합니다. 같은 ROM인지 확인하거나 다른 게임목록과 대조하는 데 쓸 수 있으며, 큰 파일이나 Android 기기 같은 연결 기기에서는 시간이 더 걸립니다.
  • 타이틀 태그 (설정): 언어·디스크 등 제목 뒤에 붙는 표기 규칙을 정합니다. 시스템 우클릭 메뉴의 제목 태그·디스크 표기 정리에서 적용 대상을 미리 보고 적용합니다. 설정 방법은 설정에 있습니다.
  • 직접 편집: 목록 파일의 원문을 직접 고쳐야 할 때는 메타데이터 직접 편집을 참고하시기 바랍니다.

문제 해결

제목을 바꿨는데 파일명이 그대로입니다.

제목은 게임 정보이고 파일명은 ROM 이름입니다. 파일명은 파일명 수정 에서 따로 바꿉니다.

저장했는데 다른 게임목록에는 반영되지 않았습니다.

저장은 상세 영역 아래의 저장 대상에만 기록됩니다. 다른 게임목록에도 반영하려면 복사·붙여넣기나 게임목록 비교를 사용합니다.

그림이 열리지 않습니다.

파일 보유 상태와 Android 기기·외부 드라이브의 연결을 확인합니다. 파일 경로를 바꿨다면 탐색·검색·정렬의 다시 스캔 으로 목록을 다시 읽습니다.

저장할 때 오류가 납니다.

대상 폴더에 쓰기 권한이 있는지, 다른 프로그램이 파일을 열고 있지는 않은지 확인합니다. 입력한 내용은 남아 있으므로 원인을 해결한 뒤 다시 저장하면 됩니다.

앱 밖에서 파일을 바꿨을 때

다른 프로그램에서 게임 정보나 미디어를 고친 뒤에는 상단 다시 스캔 또는 F5로 다시 읽습니다. 편집 중인 값이 있으면 재스캔 후에도 초안이 남습니다. 초안을 그대로 저장할 때 원본 게임 정보가 바뀐 것으로 판정되면 저장을 거부하고 충돌을 알립니다.

충돌이 나면 입력한 내용을 따로 복사해 둔 뒤 게임을 다시 선택하여 현재 파일을 읽고, 필요한 수정만 다시 적용합니다. 경로·읽기 오류나 ?가 표시되면 읽기 상태 안내를 먼저 확인합니다. 원문 직접 편집도 열었을 때와 저장할 때의 문서 상태를 비교합니다.
