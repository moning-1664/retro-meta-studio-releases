복사하기·붙여넣기

선택한 게임의 메타데이터를 다른 게임목록의 게임으로 복사합니다. 탐색기에서 파일을 복사해 붙여넣는 것과 유사한 방식으로 동작하며, 메타데이터뿐 아니라 미디어와 ROM까지 함께 보낼 수도 있습니다. 받는 곳은 탭으로 열어 둔 컬렉션(Collection)이나 보관소(Archive)입니다. 받는 쪽에 같은 게임이 이미 있으면 충돌 창이 열려, 게임마다 건너뛸지 덮어쓸지 직접 정할 수 있습니다.

복사하는 순간에는 어느 게임목록도 바뀌지 않고, 붙여넣기를 실행할 때에만 받는 쪽이 바뀝니다. 그래서 먼저 복사해 두고 받는 게임목록을 확인한 뒤에 붙여넣는 순서로 안전하게 작업할 수 있습니다.

용도와 진입 위치

게임 목록에서 선택한 항목을 복사 또는 Ctrl+C로 준비하고, 받을 Collection이나 Archive에서 붙여넣습니다. 텍스트 입력란에 초점이 있으면 Ctrl+C·Ctrl+V는 입력 내용의 복사·붙여넣기로 동작합니다.

자료 범위

범위포함 자료
메타데이터제목·설명·평점 등 게임 정보
메타데이터 + 미디어게임 정보와 연결 미디어
메타데이터 + 미디어 + ROM게임 정보·미디어·실제 게임 파일

상단의 붙여넣기 대상 아이콘으로 포함 범위를 정합니다. 현재 상세 탭을 바꾸는 동작과 자료 범위 선택은 별개입니다. ROM까지 포함할 때만 실제 게임 파일도 전송합니다.

받는 게임을 연결하는 기준

현재 전송 범위의 대상 시스템에서 파일명이 일치하는 항목을 먼저 찾습니다. 이때 시스템 별칭과 파일명 대소문자를 정규화합니다. 메타데이터·미디어 범위는 정확히 같은 파일명이 없어도 정규화된 같은 게임 후보가 하나이면 연결할 수 있습니다. 지역·디스크·보조 표기와 아케이드 계열 규칙이 여기에 사용됩니다.

ROM 포함 범위는 파일명 일치가 우선되는 더 엄격한 규칙을 사용합니다. 하위 폴더가 포함된 파일명은 다른 디렉터리의 정규화 후보로 임의 연결하지 않습니다. 후보가 여러 개이면 모호한 대상으로 처리하며 대상에 맞는 항목을 임의로 추측하지 않습니다.

선택한 기존 게임을 명시적 대상으로 붙여넣는 경로도 있습니다. 다른 파일명에 적용할 때는 충돌 화면의 게임·시스템·받는 대상을 특히 확인합니다. 비교 화면은 이미 연결한 양쪽 항목을 사용하므로 별도의 연결 규칙을 따릅니다.

붙여넣기·채우기·교체하기

방식게임 정보미디어·ROM
붙여넣기원본의 비어 있지 않은 값으로 덮어씁니다. 빈 원본 값은 기존 값을 지우지 않습니다.선택 범위의 미디어는 원본을 적용합니다. 같은 파일은 건너뛸 수 있습니다. ROM은 포함 범위와 교체 조건에 따릅니다.
채우기대상의 빈 값만 채웁니다.없는 종류의 미디어를 채우고 기존 ROM을 유지합니다.
교체하기원본의 채워진 필드로 메타데이터를 다시 구성합니다. 원본에 없는 기존 필드가 사라질 수 있습니다.원본 미디어를 적용하지만 대상에만 있는 미디어를 일괄 삭제하지 않습니다. ROM 교체는 지원 경로와 충돌 확인에 따릅니다.

채우기는 빈 값을 보완하는 방식이며 사용자가 원하는 필드만 지정하는 선택 도구는 아닙니다. 대상에 없는 게임은 원본 자료로 새로 추가됩니다.

주의

실제로 바뀌는 자료의 범위와 받는 Collection을 먼저 확인하세요. 되돌리기 제한 안내가 있는 작업은 안내에 동의한 뒤 실행됩니다.

저장과 결과

복사만으로는 받는 목록이 바뀌지 않습니다. 붙여넣기 작업을 실행해야 정보와 파일이 저장됩니다. 완료 후 적용된 대상 게임을 표시·선택하여 상세 정보를 살펴볼 수 있습니다.

완료·건너뜀·오류를 구분하고, 실행 취소가 제공되는 작업은 해당 작업의 버튼으로 되돌립니다. 저장소 연결과 백업을 유지한 채 복구 상태를 처리합니다.

문제 해결

같은 제목인데 새 게임으로 추가되거나 연결되지 않습니다.

표시 제목만으로 연결하지 않습니다. 자료 범위·시스템·파일명과 하위 경로, 정규화 후보의 개수를 확인합니다.

채우기를 했는데 제목이 바뀌지 않았습니다.

기존 값이 있으면 유지하는 방식입니다. 기존 값을 바꾸려면 차이를 검토하고 붙여넣기 또는 직접 편집을 사용합니다.
