CSV 번역

게임 설명을 CSV로 내보내 외부에서 수정하고, 대상을 검증한 뒤 설명에 반영합니다. 제목과 식별 정보는 유지하고 번역문을 전용 열에 입력합니다.

표 형태로 수백 개의 행을 한 화면에서 훑을 수 있으므로, 스프레드시트의 번역 함수·찾아 바꾸기·정렬·필터 같은 기능을 그대로 활용할 수 있다는 점이 장점입니다. 반대로 커버나 스크린샷 같은 미디어는 CSV로 다루지 않으며, 제목과 설명 외의 항목을 고치는 용도로는 적합하지 않습니다. 내보내는 열은 job_id, row_id, system, title, original, target_language, translated입니다. 수정할 곳은 translated 열의 설명입니다.

설명 번역과 일괄 편집

게임 설명을 CSV로 내보내 외부 편집기나 번역 도구에서 수정한 뒤 가져옵니다. 적용 대상은 설명이며, 제목은 게임을 확인하는 정보로 유지합니다. 커버·동영상·ROM은 CSV에 포함하지 않습니다.

내보내기와 가져오기

시스템 우클릭 메뉴의 번역 파일로 내보내기/가져오기 (.csv)에서 번역 언어를 선택하고 CSV 내보내기를 사용합니다. 현재 시스템과 선택 범위의 설명으로 번역 작업을 만듭니다. 상세 영역의 수정 내용은 먼저 저장해야 내보내기에 반영됩니다.

내보내기 뒤에는 파일명과 열 사용법이 안내됩니다. 외부 도구에서는 translated에 최종 번역문을 입력하고 CSV로 저장합니다. 앱의 CSV 가져오기에서 같은 작업의 파일을 읽어 검토합니다.

CSV 열과 수정 범위

열역할편집
job_id내보낸 번역 작업 식별값유지
row_id작업 안의 게임 행 식별값유지
system대상 시스템 확인값유지
title대상 게임 확인용 제목유지
original내보낼 때의 원래 설명유지
target_language번역 언어유지
translated가져와 적용할 설명번역문 입력

열 이름과 순서를 유지합니다. 행을 정렬해도 식별값으로 대상을 연결하지만, 제목이나 식별 열을 바꾸면 검토 오류가 됩니다. 번역 수식 대신 계산이 끝난 텍스트 값을 넣습니다. 수식·오류 셀, 중복·알 수 없는 행, 원문이 바뀐 대상은 적용 검사를 통과하지 못할 수 있습니다.

검토와 저장

가져오기는 즉시 설명을 덮어쓰지 않고 변경 내용을 검토할 상태로 만듭니다. 현재 설명·번역문·상태와 사유를 읽은 뒤 적용합니다. 내보내기 이후 대상 설명이 바뀌었거나 게임이 삭제된 경우에는 그대로 적용하지 않습니다.

적용되는 것은 translated의 설명입니다. 처리 결과에서 적용·건너뜀·오류를 구분합니다. 기기 Collection은 현재 CSV 적용을 지원하지 않으므로, 로컬 목록 또는 Archive에서 번역한 뒤 지원되는 전송 방법으로 기기 목록에 활용합니다.

파일 형식과 작업 보관

내보내기는 UTF-8 BOM CSV입니다. 가져오기는 BOM 유무를 처리합니다. 설명 속 줄바꿈·쉼표·따옴표가 한 셀의 내용으로 유지되도록 CSV 지원 편집기를 사용합니다.

앱이 보관한 번역 작업과 CSV가 연결되므로 다른 Collection의 작업 파일을 섞지 않습니다. 오래된 파일이나 이미 처리한 작업이 거부되면 현재 목록에서 새 작업을 내보냅니다.

문제 해결

제목도 번역했더니 오류가 납니다.

title은 검증용입니다. 원래 값으로 되돌리고 translated에 설명 번역문만 입력합니다. 제목 수정은 메타데이터 편집에서 진행합니다.

파일이 유효하지 않다고 나옵니다.

7개 열의 이름·순서·식별값과 내보낸 작업을 확인합니다. 수식이나 #ERROR! 같은 오류 문구를 번역문으로 저장하지 않았는지도 확인합니다.

일부 설명이 적용되지 않았습니다.

검토의 상태·사유를 읽습니다. 원문 변경·게임 삭제·중복 행·빈 번역문 등은 현재 자료와 대조한 뒤 새로 준비합니다.
