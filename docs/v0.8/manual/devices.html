Android 기기 연결

휴대용 게임기나 Android 기기에서 프론트엔드를 쓰고 있다면, 게임목록을 고칠 때마다 파일을 PC로 옮겼다가 다시 기기로 되돌려야 합니다. 이 기능은 MTP 또는 ADB로 연결된 Android 기기의 게임목록을 PC에서 직접 편집합니다. 기기의 목록을 컬렉션으로 등록해 두면 PC에 있는 게임목록과 같은 방식으로 열어 편집하고 비교할 수 있습니다. 큰 화면과 키보드, 마우스로 작업할 수 있다는 점이 가장 큰 이점입니다.

이 기능은 선택 기능이자 고급 기능입니다. 기기와 통신하는 방식이므로 PC의 폴더를 다룰 때보다 속도가 느릴 수 있습니다. 특히 미디어 파일이 많은 게임목록을 읽거나 저장할 때 시간이 오래 걸릴 수 있습니다. PC에 있는 게임목록만 다룬다면 이 페이지는 건너뛰어도 됩니다. 또한 기기에서 목록을 바로 편집하기보다, 작업은 PC의 게임목록에서 하고 완성한 결과를 기기로 옮기는 편이 빠르고 안정적일 때가 많습니다.

연결 방식 고르기

MTP와 ADB는 PC가 기기의 파일에 접근하는 서로 다른 방법입니다. 기기와 환경에 따라 한쪽만 잘 동작하기도 하므로, 먼저 준비가 간단한 MTP로 시도하고 불안정할 때 ADB로 바꾸는 방식이 무난합니다.

방식준비알맞은 때
Android MTP기기를 잠금 해제하고 USB 연결 용도를 파일 전송 으로 둡니다. Windows 탐색기에서 기기의 내부 저장 공간이 보여야 합니다.별도 설정 없이 파일을 주고받을 때
Android ADB기기의 개발자 옵션 에서 USB 디버깅 을 켜고, 기기에 뜨는 승인 창에서 이 PC를 허용합니다.MTP가 불안정하거나 큰 파일을 반복 전송할 때

개발자 옵션은 기본적으로 숨겨져 있습니다. 보통 기기의 설정에서 빌드 번호를 여러 번 눌러 표시하며, 메뉴 위치와 이름은 제조사와 Android 버전에 따라 다릅니다.

주의

USB 디버깅은 PC가 기기를 폭넓게 제어할 수 있게 하는 설정입니다. 승인 창에서는 본인이 사용하는 PC만 허용하고, 작업을 마친 뒤에는 필요에 따라 다시 끌 수 있습니다.

연결해서 등록하기

  • 기기를 케이블로 연결하고, 위의 준비를 마칩니다. 충전 전용 케이블은 데이터 전송이 되지 않으므로, 데이터 전송을 지원하는 케이블을 사용합니다.
  • 컬렉션 추가 창에서 연결 대상 을 Android MTP 또는 Android ADB 로 고릅니다.
  • 기기의 게임목록 폴더와 저장 형식을 지정합니다. 저장 형식은 기기에서 쓰는 프론트엔드(ES-DE, EmulationStation, Pegasus, LaunchBox)에 맞춥니다. 형식이 기기의 프론트엔드와 다르면 기기에서 목록을 읽지 못할 수 있으므로 정확히 맞춥니다.
  • 컬렉션 추가 완료 를 누르면 기기의 게임목록을 읽습니다. 게임이 많으면 읽는 데 시간이 걸립니다.

ADB 방식에서는 처음 연결할 때 기기 화면에 승인 창이 나타납니다. 이 창에서 이 PC를 허용해야 연결이 진행됩니다.

위 그림은 앱의 ADB 등록 화면입니다. USB 디버깅 승인은 Android 기기에 나타나는 별도 승인 안내에서 진행합니다.

등록이 끝나면 기기의 게임목록이 컬렉션으로 열립니다. 이후의 편집, 비교, 복사는 PC의 게임목록과 같은 방식으로 사용하며, 예를 들어 PC에서 잘 정리한 목록과 비교해 기기 쪽에 부족한 메타데이터를 채울 수 있습니다. 기기 쪽 게임목록을 고치기 전에는, 만일을 위해 기기의 게임목록 폴더를 PC로 복사해 백업해 두는 것을 권장합니다.

쓰는 동안 지켜야 할 것

  • 저장·전송 중에는 연결을 유지합니다. 케이블을 뽑거나 기기를 잠그면 작업이 중단될 수 있습니다. 화면 잠금 시간이 짧은 기기는 작업 전에 잠금 시간을 늘려 두는 편이 안전합니다.
  • 기기에서 파일을 바꿨다면 다시 스캔 으로 현재 상태를 읽습니다. 앱은 마지막으로 읽은 상태를 보여 주므로, 기기에서 직접 바꾼 내용은 스캔하기 전까지 반영되지 않습니다.
  • 연결이 끊기면 기록이 남아 있어도 읽기·전송이 실패합니다. 정리·삭제 전에 연결을 복구하고 상태를 읽습니다.
  • 기기에 따라 사용할 수 있는 작업이 다릅니다. 지원하지 않는 작업은 메뉴에서 비활성으로 나옵니다.
  • 기기의 저장 공간이 부족하면 저장이 실패할 수 있습니다. 용량 제약이 있는 기기나 SD카드로 옮길 때는 파일 관리의 저장공간 관리로 최대 용량을 설정하고 남은 용량을 확인합니다.
  • 기기에 있는 ROM을 PC의 RetroArch로 곧바로 실행할 수 있다고 가정하지 않습니다. 자세한 내용은 RetroArch 실행을 참고합니다.

문제 해결

기기가 목록에 없습니다.

기기 잠금, USB 연결 용도(파일 전송), ADB 승인 상태를 확인합니다. 케이블을 다시 꽂고 대상 목록을 새로 읽습니다. 그래도 보이지 않으면 데이터 전송을 지원하는 케이블인지, 다른 USB 포트에서는 인식되는지 확인합니다. MTP 방식이 계속 불안정하면 ADB 방식을 시도합니다.

ADB로 연결했는데 승인 창이 나타나지 않습니다.

USB 디버깅이 켜져 있는지, 기기 화면이 잠겨 있지 않은지 확인합니다. 케이블을 다시 연결하면 승인 창이 다시 나타나는 경우가 있습니다. ADB 승인 대기 상태라면 기기에서 USB 디버깅 승인 안내를 확인합니다. 기기별 승인 초기화 메뉴는 Android 제조사와 버전에 따라 다릅니다.

읽기와 저장이 너무 느립니다.

기기와의 통신은 PC 폴더보다 느릴 수 있으며, 미디어 파일이 많을수록 더 오래 걸립니다. 작업 중에는 연결을 유지하고 기다립니다. 큰 작업은 PC의 게임목록에서 먼저 끝낸 뒤 결과를 기기로 옮기는 방법도 있습니다.

전송 중 연결이 끊겼습니다.

기기를 다시 연결한 뒤 작업 이력과 복구에서 복구 필요 항목을 처리합니다. 원본과 백업은 지우지 않아야 합니다.

기기에서 목록을 바꿨는데 기기의 프론트엔드 화면이 그대로입니다.

앱에서는 받는 컬렉션의 저장 결과를 확인하고, 기기의 프론트엔드가 자체 목록을 유지한다면 그 프로그램에서 게임목록을 다시 읽도록 합니다.
