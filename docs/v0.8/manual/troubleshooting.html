문제가 생겼을 때

읽기 상태, 외부 변경, 폴더 재연결과 백업·로그를 설명합니다. 오류가 나면 반복해서 덮어쓰기보다 메시지에 나온 경로와 대상을 먼저 살펴보세요.

읽기 오류와 ? 표시

다시 스캔은 읽은 결과를 시스템별로 반영합니다. 오류가 생겨도 다른 시스템은 계속 읽습니다. 오류가 난 시스템의 이전 행이 남아 있더라도 최신 파일 상태로 확정된 표시로 보지 마세요.

표시뜻과 조치
시스템의 읽기 오류·경고시스템 옆 경고 버튼을 열면 문서 경로·게임 항목·문제 경로가 표시됩니다. 드라이브 연결, 파일 읽기 권한, 메타데이터 문법과 경로를 고친 뒤 다시 스캔합니다.
메타데이터 개수의 ?일부 메타데이터를 확실하게 식별하지 못해 개수를 확정하지 못한 상태입니다. 0개와 다릅니다. 읽기 경고의 문서·항목을 점검합니다.
게임 정보의 식별 불확실 안내불확실한 게임 정보의 저장·내보내기를 제한합니다. 물리 ROM 상태와 이전 메타데이터 표시가 함께 보일 수 있습니다. 원본 문서 문제를 해결해 다시 읽습니다.
링크 건너뜀ROM 폴더의 링크를 따라가서 범위 밖 파일을 변경하지 않도록 건너뛴 것입니다. 의도한 위치의 실제 파일을 사용하고 시스템 경고에서 경로를 읽습니다.

외부 변경과 다시 스캔

현재 탭 상단의 다시 스캔 또는 F5를 사용합니다. 전체 게임목록을 보고 있으면 전체 시스템을, 특정 시스템 범위에서는 그 범위를 다시 읽습니다. 읽기 식별 복구가 필요한 상태에서는 전체 범위를 다시 읽을 수 있습니다.

컬렉션은 메타데이터+커버를 먼저 읽고 나머지 미디어를 이어서 읽습니다. 미디어만 읽는 별도 사용자 선택 버튼으로 구분된 기능은 아닙니다. 완료된 시스템부터 표시되며, 1단계가 끝났다고 전체 작업이 끝난 것은 아닙니다. 보관소(Archive)의 다시 스캔은 보관소 갱신 작업으로 처리됩니다.

현재 편집 초안은 재스캔 중 유지합니다. 외부 프로그램이 같은 게임 정보를 바꾸었다면 저장 시 충돌 검사를 통과해야 합니다. 입력을 따로 보관하고 게임을 다시 선택한 뒤 변경 내용을 대조하세요. 편집 중 외부 변경도 참고하세요.

폴더를 복원하거나 교체했을 때

같은 경로에 다른 폴더를 넣거나 백업에서 폴더를 복원하면 앱이 이전 폴더와 다른 대상으로 인식할 수 있습니다. 탐색 영역의 현재 폴더로 재연결을 누르고, 표시된 경로가 의도한 폴더인지 직접 확인합니다.

재연결은 현재 폴더를 이 컬렉션의 대상으로 승인하고 이전에 준비한 작업 계획을 해제합니다. 편집 초안은 유지하며, 파일 읽기는 자동으로 시작하지 않습니다. 승인 후 다시 스캔을 직접 실행합니다. 빈 폴더를 승인하면 다음 스캔에서 기존 목록이 없어질 수 있으므로 원본이 준비된 위치인지 확인하세요.

연결이 끊긴 드라이브는 먼저 다시 연결합니다. 폴더가 바뀐 것이 아닌데 오류가 난 경우, 임시로 빈 폴더를 만들어 우회하지 마세요. 과거 작업 기록의 복구 대상은 재연결만으로 새 폴더에 바뀌지 않습니다.

백업과 복구

작업 전 원본 보관은 탐색기에서 게임목록 폴더와 별도 미디어·ROM 폴더를 복사하는 방법으로 진행합니다. 앱의 작업 백업은 지원 작업이 바꾼 자료와 복구 기록을 보관합니다. 전체 게임 자료를 한 번에 복제하는 백업과 범위가 다릅니다.

백업 위치와 보관 설정, 실행 취소 지원 범위를 참고하세요. 복구 실패 시 원본·대상·백업을 지우지 말고 오류 메시지를 남깁니다. 폴더를 복원하기 전에는 앱의 쓰기 작업을 끝내고 앱을 종료합니다.

설치 파일과 체크섬

배포 파일은 공식 GitHub 릴리즈의 Setup 또는 Portable ZIP에서 받습니다. 같은 릴리즈의 SHA256SUMS.txt와 파일의 해시를 대조합니다.

Get-FileHash -Algorithm SHA256 -LiteralPath 'C:\Downloads\받은파일.zip'

Windows가 출처·실행 경고를 표시하면 다운로드 주소·파일명·해시를 먼저 대조합니다. 일치하지 않는 파일은 실행하지 않습니다. 코드 서명 여부는 실제 배포 파일의 속성에서 확인해야 하며, 이 설명서는 미검증 파일이 서명되었다고 보증하지 않습니다. 백신을 일괄 끄는 방법으로 우회하지 마세요.

문의와 로그

설정 → 정보 → 로그 폴더 열기에서 현재 로그 폴더를 엽니다. 기본 로그는 실행 파일 옆 logs/retrometa.log이며, 이전 로그는 번호가 붙어 남을 수 있습니다. 같은 화면의 진단 정보 복사 기능으로 앱 버전과 환경을 준비합니다.

GitHub Q&A에 앱 버전, 목록 형식, PC·MTP·ADB 구분, 재현 순서, 기대 결과, 오류 화면을 적습니다. 로그와 화면의 계정·토큰·개인 경로는 가리고 올립니다. 계정 없이 문의하는 별도 채널은 아직 안내하지 않습니다.
