보관소(Archive)

여러 게임목록에서 모은 메타데이터와 자료를 한곳에 보관하고, 출처와 변경 이력을 남깁니다. 같은 게임에 대해 서로 다른 설명이나 커버가 여러 개 쌓여 있어도 어느 목록에서 왔는지 알 수 있고, 필요할 때 원하는 버전을 골라 게임목록으로 다시 가져올 수 있습니다. 처음부터 설정할 필요는 없으며, 여러 목록을 오가며 정리하는 일이 늘어날 때 도입하면 됩니다.

컬렉션과 어떻게 다른가

보관소(Archive)는 앱에 등록되어 탭으로 열린 게임목록인 컬렉션(Collection)과 성격이 다릅니다. 컬렉션은 지금 사용하는 게임목록 자체이고, 저장소는 여러 컬렉션에서 모아 둔 자료의 보관 장소입니다.

컬렉션보관소(Archive)
역할지금 쓰는 폴더의 게임목록을 편집여러 출처의 자료를 모아 보관
저장되는 곳프론트엔드 형식의 파일(예: ES-DE의 목록 파일)보관소 폴더
이력일반 파일 작업 이력과 실행 취소 상태게임별 변경 기록과 출처
편집 내용을 게임목록에 반영하려면보기 모드에 따른 저장 동작으로 해당 목록에 기록합니다.저장소에서 고친 내용은 컬렉션으로 가져오기 를 실행해야 반영됩니다.

어떤 때 쓰나

  • 여러 게임목록의 설명과 커버를 한곳에 모아 두고 재사용할 때
  • 같은 게임의 서로 다른 정보(예: 지역별 제목, 다른 번역)를 비교하고 보존할 때
  • 선호하는 버전을 정해 두고, 다른 컬렉션에 가져올 때 그 버전을 우선 쓰고자 할 때
  • 게임목록을 변환하거나 정리하다가 이전 내용을 잃을까 걱정될 때, 이전 상태를 기록으로 남겨 둘 때

시작하기

  • 시작 화면의 통합 보관소 설정 또는 설정의 보관소(Archive) 에서 보관소 폴더를 지정합니다. 용량이 충분한 드라이브의 빈 폴더를 권장합니다. 미디어가 쌓이면 폴더가 커질 수 있습니다.
  • Archive 탭이 나타납니다.
  • 컬렉션에서 게임을 선택해 Archive로 보내기 를 실행합니다.
  • 검토 화면에서 게임 연결, 변경될 내용, 파일 작업을 확인하고 적용합니다.
  • Archive 탭에서 보관된 게임과 변경 이력을 확인합니다.

화면 구성

번호항목하는 일
①보관소 위치저장소의 자료와 기록이 저장되는 폴더입니다. 백업할 때 이 폴더를 대상으로 합니다.
②게임목록보관된 게임을 시스템·검색·보기 모드로 탐색합니다.
③출처·보유 상태보관 파일과 외부 위치에 연결된 자료를 구분하고, 어느 컬렉션에서 왔는지 보여 줍니다.
④변경 이력게임의 서로 다른 정보와 미디어 기록을 시간 순서로 보여 줍니다.
⑤다른 컬렉션 활용받을 컬렉션에서 저장소를 원본으로 선택해 가져오는 진입점입니다.

기록과 선호 기록

Revision 탭은 같은 게임에 보관된 기록을 출처와 함께 보여 줍니다. CURRENT는 현재 사용 중인 기록입니다. 다른 기록 카드를 선택한 뒤 이 버전 사용을 누르면 그 기록을 우선 사용하도록 지정하며, 목록과 상세 정보가 함께 갱신됩니다. 게임목록으로 실제 파일을 전송하는 작업은 컬렉션에서 가져오기에서 별도로 실행합니다.

서로 다른 값은 강조색으로 표시합니다. 자세히는 기록의 추가 정보와 자료를 펼칩니다. 현재 기록은 버전 삭제가 비활성화됩니다. 자동 선택으로 돌아가면 가장 최근 판을 사용합니다. 기록 선택은 실패한 파일 작업을 복구하는 기능과 구분합니다.

  • 같은 내용의 기록은 하나로 묶어서 표시하므로, 목록이 불필요하게 길어지지 않습니다. 서로 다른 값과 미디어를 중심으로 출처를 비교할 수 있습니다.
  • 선호 기록(PREFERRED) 은 컬렉션에 가져올 때 우선해서 쓸 버전을 정해 두는 표시입니다. 게임의 즐겨찾기와는 별개이며, 즐겨찾기 상태에는 영향을 주지 않습니다.

보관 파일과 외부 연결 파일

저장소에 보낸 자료는 두 가지 방식으로 존재할 수 있습니다.

구분뜻쓸 수 있는 조건
보관 파일보관소 폴더 안에 복사해 둔 파일항상 사용할 수 있습니다.
외부 연결 파일원래 컬렉션이나 외부 드라이브에 있는 파일을 가리키기만 하는 연결원래 위치가 연결되어 있을 때만 사용할 수 있습니다.

외부 연결 파일은 보관소 폴더의 용량을 늘리지 않는 대신, 원래 위치가 이동·삭제되거나 드라이브가 분리되면 쓸 수 없습니다. 또한 보관된 게임의 수와 실제로 ROM을 보유한 게임의 수는 다를 수 있습니다. 메타데이터만 보관하고 ROM은 보관하지 않은 게임도 있기 때문입니다.

컬렉션으로 가져오기

  • 받을 컬렉션을 열고 가져오기 도구에서 Archive 를 원본으로 고릅니다.
  • 연결된 게임과 제공되는 정보·미디어를 확인합니다. 선호 기록이 지정된 게임은 그 버전이 우선 제안됩니다. 선호 판을 지정하면 Archive에서 가져올 기본 정보의 우선 기록으로 사용합니다. 즐겨찾기는 게임 표시용이며 선호 판과 별도입니다.
  • 가져올 항목을 고르고, 겹치는 항목은 검토 화면에서 하나씩 결정합니다.

자세한 방법은 컬렉션에서 가져오기에 있습니다.

공유·백업·삭제

  • 다른 앱이나 다른 PC에서 저장소를 고쳤다면 최신 상태 안내나 충돌 안내가 나올 수 있습니다. 진행 중인 작업을 끝낸 뒤 안내에 따라 최신 상태를 읽어 들입니다.
  • 백업 은 앱을 종료한 뒤 보관소 폴더 전체를 복사합니다. 앱이 실행 중일 때 복사하면 기록과 파일이 어긋난 상태로 복사될 수 있습니다.
  • 기록 제거와 보관소 폴더 내부 파일 삭제는 서로 다른 작업입니다. 삭제 확인 창에서 대상과 파일에 미치는 영향을 읽고 진행합니다.
주의

보관소 폴더를 탐색기에서 직접 옮기거나 이름을 바꾸면 앱이 기록과 파일을 연결하지 못할 수 있습니다. 위치를 바꿀 때는 앱의 설정에서 변경하시기 바랍니다. 앱을 종료하고 보관소 폴더 전체를 새 위치에 복사한 뒤 보관소 설정에서 새 폴더를 연결합니다. 원래 폴더는 새 위치의 자료가 확인될 때까지 유지합니다.

문제 해결

보관된 게임의 ROM을 쓸 수 없습니다.

ROM 보유 상태와 원본 경로를 확인합니다. 외부 연결 파일이라면 원래 위치의 드라이브를 다시 연결해야 합니다.

다른 앱이 사용 중이라고 나옵니다.

저장소를 열어 둔 다른 앱이나 다른 PC의 작업을 끝내고 닫은 뒤 다시 시도합니다. 중단된 작업은 작업 이력과 복구에서 처리합니다.

저장소에서 고친 내용이 게임목록에 보이지 않습니다.

저장소의 편집은 자동으로 컬렉션에 반영되지 않습니다. 받을 컬렉션에서 가져오기를 실행합니다.
