탐색·검색·정렬

게임이 수천 개에 이르는 게임목록에서도 원하는 게임만 화면에 남기도록, 시스템 선택·검색·필터·정렬을 조합하는 방법을 설명합니다. 네 가지는 따로 동작하지 않고 함께 적용됩니다. 따라서 "게임이 안 보인다"는 문제의 대부분은 이 조합 중 하나가 범위를 좁히고 있어서 생깁니다.

번호도구하는 일
①전체 게임·시스템현재 컬렉션 전체 또는 선택한 시스템의 게임만 보여 줍니다. 편집·가져오기·스크랩의 범위도 이 선택을 기준으로 정해집니다.
②이름 표시시스템 이름 표기를 바꿉니다. 표시만 바뀌며 실제 폴더 이름은 그대로입니다.
③빈 시스템 숨기기게임이 없는 시스템을 탐색 목록에서 숨겨 목록을 짧게 만듭니다.
④검색현재 범위에서 제목·파일명을 찾습니다. 시스템을 고른 상태라면 그 시스템 안에서만 찾습니다.
⑤필터즐겨찾기 등 선택한 조건으로 게임을 좁힙니다. 기본 목록은 즐겨찾기와 ROM·메타데이터·미디어 관련 표시 조건을 조합합니다. 비교 모드의 상태 필터는 목록 간 비교에서 별도로 설명합니다.
⑥정렬·우선 정렬열(파일·제목·설명·평점 등)을 기준으로 정렬하고, 자료 보유 상태에 따른 우선 정렬(전체보기, ROM 우선 등)을 고릅니다. 목록 열의 필드 정렬과 전체보기·ROM 우선·메타데이터 우선·미디어 우선·언어 우선을 조합합니다. Archive에는 변경 이력 우선 표시가 추가됩니다.
⑦탐색 영역 손잡이시스템 영역의 너비를 바꿉니다.

시스템 이름 표시

이름 표시 버튼을 누를 때마다 세 가지 방식이 순서대로 바뀝니다. 같은 시스템이라도 어떤 이름으로 보는 것이 편한지는 작업에 따라 다릅니다.

방식예시알맞은 때
폴더명nes실제 저장된 폴더와 대조할 때
플랫폼NES짧은 이름으로 여러 시스템을 훑어볼 때
전체 이름Nintendo Entertainment System게임기의 정식 이름을 확인할 때

표시만 바뀝니다. 실제 폴더 이름은 바뀌지 않습니다. 폴더 이름 자체를 바꾸려면 시스템 우클릭 메뉴의 폴더 이름 변경을 사용합니다(메뉴와 단축키 참고). 상단 요약 영역에는 표시 방식과 관계없이 항상 전체 이름이 나옵니다.

탐색 영역 너비

시스템 영역과 게임목록 사이의 손잡이를 좌우로 드래그해 너비를 바꿉니다. 시스템 이름이 길어 잘릴 때는 넓히고, 게임목록을 넓게 쓰고 싶을 때는 좁힙니다.

  • 손잡이를 더블클릭하면 기본 너비와 최소 너비 사이를 오갑니다.
  • 최소 너비에서는 아이콘 중심으로 표시됩니다. 이때 전체 게임·시스템·추가 버튼·Dashboard·설정이 같은 너비로 함께 움직입니다.

검색 범위가 합쳐지는 방식

시스템 + 검색어 + 필터가 모두 동시에 적용됩니다. 예를 들어 시스템이 NES이고 검색어가 "mario"이며 즐겨찾기 필터가 켜져 있다면, NES의 즐겨찾기 게임 중에서 "mario"가 들어간 것만 나옵니다. 찾는 게임이 보이지 않을 때는 아래 순서로 범위를 하나씩 풀어 봅니다.

  • 시스템을 전체 게임 으로 바꿉니다.
  • 검색어를 지웁니다.
  • 켜 둔 필터를 끕니다.
  • 빈 시스템 숨기기가 켜져 있다면, 시스템 목록에서 해당 시스템이 빠지지 않았는지 확인합니다.

이 순서로 풀어도 보이지 않는다면 게임이 목록에 없거나 읽기가 끝나지 않았을 가능성이 있으므로, 아래의 다시 스캔 을 실행합니다.

참고

검색·필터·정렬은 지금 화면에 보이는 범위에만 적용됩니다. 어떤 도구가 켜져 있는지 확인하지 않은 채 복사·스크랩 같은 작업을 시작하면 보이는 게임만 대상이 될 수 있으므로, 작업 전에 하단 상태 영역의 항목 수와 선택 수를 확인합니다.

새로고침과 자료 상태

다시 스캔 은 게임목록과 실제 파일을 다시 읽어 현재 상태로 맞춥니다. 탐색기에서 ROM이나 미디어를 옮기거나 다른 프로그램으로 목록을 고쳤을 때처럼, 앱 밖에서 파일이 바뀐 경우에 사용합니다. 컬렉션 새로고침은 처리가 끝난 시스템부터 목록에 반영하므로, 규모가 큰 게임목록에서는 시스템이 하나씩 나타납니다.

게임 정보만 관리하는 컬렉션에서의 "ROM 없음"과, ROM을 관리하는 컬렉션에서의 "파일 없음"은 의미가 다릅니다. 앞의 것은 ROM을 연결하지 않았으니 정상인 상태이고, 뒤의 것은 목록에는 있는데 ROM 파일이 빠져 있는 상태입니다. 후자는 파일을 복구하거나 파일 관리의 정리 기능으로 처리합니다.

문제 해결

게임 수가 예상보다 적습니다.

시스템·검색어·필터·빈 시스템 숨기기를 차례로 확인합니다. Android 기기를 연결해 쓰고 있었는데 연결이 끊겼다면, 연결을 복구한 뒤 다시 스캔 을 실행합니다.

시스템이 탐색 목록에 없습니다.

빈 시스템 숨기기가 켜져 있으면 게임이 없는 시스템은 보이지 않습니다. 끄고 다시 확인합니다. 게임이 있어야 하는 시스템이라면 아직 읽기가 끝나지 않았을 수 있습니다.

시스템 이름이 폴더 이름과 다르게 나옵니다.

이름 표시 방식이 플랫폼 또는 전체 이름으로 되어 있을 수 있습니다. 이름 표시 버튼으로 폴더명 표기로 바꿔 대조합니다.
