컬렉션에서 가져오기

지금 작업 중인 게임목록의 게임에 맞는 후보를, 열어 둔 다른 게임목록에서 찾아 메타데이터를 가져옵니다. 이미 잘 정리해 둔 게임목록을 재사용하는 방법으로, 같은 게임의 설명과 커버를 처음부터 다시 입력하거나 스크랩하지 않아도 됩니다. 원본으로는 탭으로 열어 둔 컬렉션(Collection)과 설정을 마친 보관소(Archive)를 쓸 수 있습니다.

용도

  • 다른 게임목록에 이미 정리된 설명·커버를 현재 게임목록에 가져올 때: 수작업으로 정리한 쪽을 원본으로 삼아 비어 있는 쪽을 채웁니다.
  • 시스템 하나, 또는 게임목록 전체를 한 번에 맞출 때: 게임 하나씩 복사하지 않고 후보를 일괄로 찾아 연결합니다.
  • 후보를 눈으로 확인하면서 연결하고 싶을 때: 후보와 현재 정보를 나란히 비교한 뒤에 적용합니다.

두 게임목록의 차이를 먼저 보고 싶다면 목록 간 비교를, 몇 개만 골라 보내려면 복사·붙여넣기를 씁니다. 구분은 정보를 옮기는 방법 고르기에 있습니다.

사전 준비

  • 원본으로 쓸 게임목록을 컬렉션 탭으로 열어 둡니다. 열려 있지 않으면 원본 선택에 나타나지 않습니다.
  • 보관소(Archive)를 원본으로 쓰려면 저장소 설정이 끝나 있어야 합니다.
  • 받는 게임목록은 작업을 시작한 쪽입니다. 현재 탭이 받는 쪽이 되므로, 가져오기를 시작하기 전에 탭이 맞는지 확인합니다.
  • 변경될 수 있는 게임목록은 작업 전에 폴더를 복사해 두면 안전합니다.

메뉴와 적용 대상

  • 받을 게임목록에서 가져오기 도구를 엽니다. 게임 하나는 해당 게임에서, 시스템 범위는 시스템 메뉴에서 시작합니다.
  • 원본으로 쓸 컬렉션 또는 저장소를 고릅니다.
  • 현재 게임과 후보를 비교해 연결할 후보를 선택합니다.
  • 적용합니다. 끝나면 적용·건너뜀·오류를 구분해 보여 줍니다.

화면 구성

번호항목하는 일
①원본 선택현재 탭을 제외하고 열려 있는 컬렉션과 설정된 저장소를 보여 줍니다. 목록에 없는 원본은 먼저 탭으로 열거나 저장소를 설정합니다.
②현재 게임·후보현재 정보와 원본의 후보를 나란히 보여 줍니다.
③후보 선택시스템·파일명·정보·미디어를 대조해 연결할 자료를 고릅니다.
④적용 결과처리된 대상과 건너뛰거나 실패한 사유를 보여 줍니다.

후보를 정하는 방식

  • 여러 항목을 한꺼번에 가져올 때, 정확히 일치하는 후보가 하나뿐인 항목은 자동으로 처리할 수 있습니다. 확인할 필요가 없는 항목에서 시간이 절약됩니다.
  • 후보가 여럿이거나 모호한 항목은 현재 게임과 후보를 대조해 직접 고릅니다. 같은 제목이라도 지역·디스크·판이 다를 수 있으므로 정보와 미디어를 함께 봅니다.
  • 후보 없음과 건너뛰기는 적용 개수에 들어가지 않습니다. 결과 창의 적용 개수가 선택한 게임 수보다 적은 것은 이 때문입니다.
  • 준비 중 취소하면 남은 후보 준비를 멈춥니다. 후보를 준비한 상태와 실제 적용한 상태를 구분하고, 적용 중단은 작업의 완료·오류·복구 결과를 기준으로 처리합니다.

어디까지 들어오나

원본의 자료가 받는 게임목록으로 들어옵니다. 후보 선택과 자료 적용은 연결된 대상과 현재 붙여넣기 방식에 따라 처리됩니다. 실제 파일이 필요하면 원본의 파일 위치에 접근할 수 있어야 합니다. 붙여넣기 방식의 의미는 복사·붙여넣기의 붙여넣기 방식 표를 참고하시기 바랍니다. 현재 붙여넣기 방식과 자료 범위를 사용합니다. 후보 선택 후 충돌 검토가 필요한 게임은 기존/들어오는 자료를 비교해 결정합니다.

참고

가져오기는 원본 게임목록을 바꾸지 않습니다. 변경은 받는 쪽에서만 일어납니다.

끝난 뒤

  • 결과 창에서 적용·건너뜀·오류의 개수를 확인합니다. 오류가 있으면 사유를 읽고 해당 게임만 다시 시도합니다.
  • 적용된 게임은 받는 게임목록에서 제목·설명·미디어를 직접 열어 확인합니다.
  • 되돌릴 수 있는 작업은 작업 이력과 복구에서 실행 취소합니다. 실행 취소 가능 여부는 작업의 undo 지원과 연결 방식에 따라 다릅니다. 작업 결과와 이력에 제공되는 버튼을 기준으로 하며, 실행 전 표시되는 되돌리기 제한 안내를 따릅니다.

문제 해결

원본 목록이 선택 창에 없습니다.

원본 게임목록을 컬렉션 탭으로 열어 둡니다. 저장소는 설정을 마쳐야 원본이 됩니다. 현재 작업 중인 탭 자신은 원본 목록에서 제외됩니다.

같은 제목의 후보가 여러 개입니다.

시스템·지역·디스크·파일명과 설명을 함께 비교해 맞는 판을 고릅니다. 확신이 서지 않는 항목은 건너뛰고 나중에 직접 정리합니다.

일부 게임이 후보 없음으로 나옵니다.

원본에 같은 게임이 없거나 시스템·파일명이 달라 연결되지 않은 경우입니다. 원본에 해당 게임이 있는지 확인하고, 없다면 스크랩으로 채웁니다.
