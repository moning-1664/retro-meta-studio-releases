릴리즈 노트

기능 개선·성능 개선·오류 수정을 버전별로 정리했습니다.

v0.8b

공개일: 미정 · 현재 문서는 v0.8b 계열 개발판 기준입니다. 검증 중인 실행 파일의 기능과 실제 배포 파일은 구분합니다.

기능 개선

  • 아케이드 보기 개편: 게임 화면·커버·설명을 함께 보며 내용을 편집하기 쉬워졌습니다.
  • 새 시작화면과 테마: 보기 모드와 테마를 고르고 원하는 화면으로 작업을 시작할 수 있습니다.
  • 탐색 영역 조절: 시스템 목록의 너비와 이름 표시를 작업에 맞게 고를 수 있습니다.
  • 편집과 가져오기: 제목 생성·파일명 수정의 선택을 분명하게 하고, 비교·가져오기에서 대상과 복사 범위를 더 쉽게 확인하도록 했습니다.
  • 실행과 파일 확인: PC RetroArch 설정과 ROM SHA256 조회 등을 개선했습니다.
  • 사용 설명서 개편: 그림 중심의 처음 사용하기와 화면·기능별 설명을 함께 제공합니다.

성능 개선

  • 게임이 많은 목록에서 먼 위치로 스크롤할 때 생기는 대기를 줄였습니다.
  • Archive 상세 정보와 관련 미디어를 불러오는 흐름을 개선했습니다.
  • Collection 새로고침은 완료된 플랫폼부터 목록에 반영하도록 했습니다.
  • 탭 전환과 백그라운드 작업 중 현재 상태를 확인할 수 있도록 로딩 안내를 정리했습니다.

오류 수정과 안정성 개선

  • 메타데이터가 없는 게임에서 표시 제목과 실제 파일명을 혼동하기 쉬웠던 편집 흐름을 고쳤습니다.
  • Archive 변경 이력과 미디어 보관·복구 처리를 보완했습니다.
  • 외부 변경 충돌·폴더 교체·시스템별 읽기 실패를 구분해 안내하고, 식별이 불확실한 메타데이터의 저장을 제한합니다. 표시 의미와 대처 방법을 설명서에 추가했습니다.
  • 하위 폴더의 ROM을 별도 항목으로 구분하고, 로컬 CUE/M3U 묶음과 공유 구성 파일의 변경 검사를 보완했습니다.
  • Android 기기 연결·전송·복구의 오류 처리와 안내를 개선했습니다.
  • 좁은 화면·높은 배율·여러 언어에서 겹침과 표시 누락을 수정했습니다.
  • 테마별 CSS 충돌과 백엔드의 오류·작업 대기열 처리를 정리했습니다.

v0.7 — 개발 이력

2026년 10월 16일까지의 미배포 개발 이력입니다. 별도 실행 파일이 배포된 버전은 아닙니다.

기능 개선

  • 글꼴·화면 밀도·편집 창을 정리했습니다.
  • 비교·가져오기·충돌 확인 화면의 조작과 결과 안내를 통일했습니다.
  • 스크랩 후보의 정보와 미디어를 간결하게 확인하도록 했습니다.
  • 설명 CSV 내보내기·가져오기 개발을 진행했습니다. 현재 v0.8b 개발판의 사용 방법은 CSV 번역에 있습니다.
  • Android ADB 연결 진단과 읽기 전용 스캔 미리보기 개발을 진행했습니다. 현재 연결·진단 안내는 Android 기기 연결에 있습니다.

오류 수정과 사용성 개선

  • 가져오기 준비를 취소하거나 대화상자를 닫을 때의 처리를 정리했습니다.
  • 비교 범위와 작업 방향을 확인하기 쉽게 했습니다.
  • 형식을 인식하지 못한 CSV의 안내와 오래된 UI 파일이 남는 문제를 개선했습니다.

v0.6b — 공개 배포

공개일: 2026년 10월 11일 (한국 시간) · GitHub의 공개 시각은 2026-10-10 15:44 UTC입니다.

기능 개선

  • Windows Setup과 Portable ZIP을 제공했습니다.
  • ROM 복사 선택과 우클릭 메뉴를 정리했습니다.
  • 라이선스와 외부 구성요소 고지를 배포물에 포함했습니다.

성능 개선

  • Collection/Archive 대시보드 로딩과 미디어 집계를 개선했습니다.

오류 수정과 사용성 개선

  • 미디어 정리와 중복 ROM 정보 합치기를 개선했습니다.
  • 붙여넣기 후 선택·포커스와 진행률·남은 시간 안내를 다듬었습니다.

v0.6b 다운로드와 당시 릴리즈 설명

지원 제한과 알려진 상태

항목현재 범위
배포 버전공개 실행 파일은 v0.6b입니다. v0.8b의 공개일·설치 파일은 아직 확정되지 않았습니다.
실제 환경 검증문서의 로컬·자동 검사 결과가 모든 MTP/ADB 기기·네트워크 저장소에서의 동작을 보증하지는 않습니다.
게임 실행PC의 로컬 ROM과 RetroArch·코어를 별도로 준비합니다. 연결 기기의 ROM을 PC RetroArch로 직접 실행하는 경로는 제한됩니다.
CSV·목록 형식CSV는 설명 번역용입니다. Pegasus의 지역 필드는 공통 편집·저장을 지원하지 않습니다.
오류와 복구읽기 오류·외부 변경 충돌·폴더 재연결은 문제가 생겼을 때, 실행 취소 범위는 작업 이력과 복구에서 다룹니다.

확인된 오류는 GitHub Q&A에서 문의할 수 있습니다. 별도의 이메일 지원 주소는 현재 안내하지 않습니다.
